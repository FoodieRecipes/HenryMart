# HenryMart - Foodie's Store

A simple, modern, and fully functional retail website built with **HTML, CSS, and JavaScript**.



## ✨ Features

- ✅ Responsive Design (Mobile + Desktop)
- ✅ Fully Functional Shopping Cart (with localStorage)
- ✅ Product Details Page
- ✅ Admin Dashboard
- ✅ Comment / Instruction System (Dr. Anietie)
- ✅ Checkout Page
- ✅ About & Contact Pages
- ✅ Clean UI with modern styling

## 🛠️ Technologies Used

- HTML5
- CSS3 (Custom properties + Flexbox + Grid)
- Vanilla JavaScript
- No frameworks required


## 🚀 How to Run Locally

1. Clone or download the project
2. Open `index.html` in your browser
3. Start shopping!
